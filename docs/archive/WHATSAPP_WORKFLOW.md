# WhatsApp Workflow

WhatsApp: Caça Oferta Oficial.

## MVP

O app gera mensagem curta para copiar e colar manualmente.

Não usar:

- WhatsApp Web automatizado.
- Selenium.
- Playwright.
- Bibliotecas não oficiais.

## Futuro

Preparar integração com WhatsApp Cloud API oficial apenas após aprovação de custos e configuração.
