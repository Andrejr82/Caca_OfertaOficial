# Free Tier Limits

O MVP deve usar apenas recursos gratuitos:

- Vercel Hobby.
- Supabase Free.
- GitHub Free.
- Telegram Bot API.
- Bibliotecas open-source.

## Riscos

- Supabase Free tem limites de banco, storage e autenticação.
- Vercel Hobby tem limites de build e execução.
- Telegram Bot API pode impor limites de envio.

## Monitoramento

Verifique mensalmente:

- Uso de banco e storage no Supabase.
- Builds e bandwidth na Vercel.
- Volume de posts no Telegram.

Serviços pagos exigem aprovação explícita.
