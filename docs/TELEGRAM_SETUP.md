# Telegram Setup

## Canal

- Nome: Caça Oferta Oficial
- URL: https://t.me/caca_ofertaoficial

## Bot

1. Abra BotFather.
2. Crie um bot.
3. Copie o token para `TELEGRAM_BOT_TOKEN`.
4. Adicione o bot ao canal.
5. Promova o bot a administrador com permissão de postar.
6. Configure `TELEGRAM_CHANNEL_ID=@caca_ofertaoficial`.

## Teste

Na tela Telegram:

- Testar conexão valida o bot.
- Publicar envia apenas ofertas aprovadas.
- O token nunca é exibido no frontend.
