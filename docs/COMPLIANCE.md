# Compliance

## Transparência

Sempre informar que links podem gerar comissão.

## WhatsApp

Não fazer spam.
Enviar mensagens apenas para pessoas que aceitaram receber.
Usar Cloud API oficial em automações futuras.

## Instagram

Usar conta profissional.
Não usar automação de login ou bots de engajamento.
Usar Graph API oficial quando autorizado.

## Telegram

Usar Bot API oficial.
Evitar excesso de postagens e conteúdo enganoso.
