# PROTOCOLO OFICIAL DAS LLMS PARA A RELEASE V5

Toda LLM (Claude, Gemini, GPT, Codex ou qualquer outra) deverá executar exatamente o mesmo procedimento documentado.
A inteligência da LLM jamais substituirá o processo. O processo será a autoridade máxima.

## REGRAS DE INICIAÇÃO
Toda LLM deverá iniciar obrigatoriamente lendo:
- `RELEASE/CONSTITUICAO_RELEASE.md`
- `PMAV5/SSOT.md`
- `PMAV5/CONSTITUICAO_PMAV5.md`
- Todos os Runbooks.

## REGRAS DE DECISÃO
Toda decisão deverá citar explicitamente:
- documento
- ADR
- contrato
- arquivo
- ou código
que fundamenta a decisão.

**Caso não exista fundamento:**
**ABORTAR.**

Nenhuma LLM poderá depender:
- da memória da conversa;
- de recomendações anteriores;
- de contexto externo;
- de interpretações subjetivas.
