# Non-Functional Requirements

| ID | Requirement |
| --- | --- |
| RNF001 | The MVP must use only free-tier tools unless the user explicitly approves paid services. |
| RNF002 | Secrets must never be committed, displayed in the frontend or logged. |
| RNF003 | Supabase Row Level Security must protect all private tables. |
| RNF004 | The application must be deployable on Vercel Hobby. |
| RNF005 | Code must be TypeScript-first and maintain clear server/client boundaries. |
| RNF006 | The dashboard must remain usable on desktop and mobile. |
| RNF007 | Build, typecheck, tests and security checks must be runnable locally. |
| RNF008 | Future affiliate APIs must be represented by safe stubs, not paid integrations. |
| RNF009 | Auditability requires posts, integration logs, links and sales records. |
| RNF010 | The UI must avoid leaking operational secrets or internal tokens. |
