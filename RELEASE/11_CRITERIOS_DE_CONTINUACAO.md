# CRITÉRIOS DE CONTINUAÇÃO

A Release pode prosseguir exclusivamente quando:

- Todos os itens do Checklist Universal obrigatório para a fase atual estiverem aprovados.
- A decisão ou execução for totalmente fundamentada em:
  - Constituição
  - Governança
  - Runbooks
  - ADRs
  - Contratos
  - SSOT
  - Código
  - Git
  - Documentação versionada
- Existirem evidências explícitas registradas do sucesso da etapa anterior.
- Todos os contratos de integração (Shopee, Mercado Livre, Amazon) estiverem validados e intactos.
- O repositório (SSOT) se mantiver como a única e definitiva fonte da verdade, sem dependência de contexto externo.
