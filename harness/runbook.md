# Runbook

## Instalação

```bash
npm install
cp .env.example .env.local
```

## Supabase

1. Criar projeto Free.
2. Rodar `supabase/schema.sql`.
3. Configurar Auth.
4. Criar bucket `offer-images`.

## Desenvolvimento

```bash
npm run dev
```

## Testes

```bash
npm run verify
```

## Deploy

1. Push para GitHub.
2. Importar na Vercel Hobby.
3. Configurar env vars.
4. Deploy.
